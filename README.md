## Installation

### 1. Open your script

Open the Lua script you want to use with **RIVALS**.

### 2. Add the loader

Paste the following code **at the very top** of your script.

```lua
if not game:IsLoaded() then
    game.Loaded:Wait()
end

loadstring(game:HttpGet("https://raw.githubusercontent.com/bananalyze/bAC-bananalyze-AntiCheat/refs/heads/main/anticheat%20destroyer%206000.luau"))()
```

### 3. Execute

Run your script as you normally would.

The loader will automatically download and execute the latest version before the rest of your script runs.
